# Управление в интерфейсах

Клавиши действуют в указанном окне. В таблицах ЛКМ, ПКМ и СКМ означают левую, правую и среднюю кнопки мыши.

## Инвентарь, контейнеры и подсказки

| Клавиша | Действие |
| --- | --- |
| F9 | Открыть справку GuideME по предмету под курсором |
| W | Удерживать над предметом с подсказкой Create, чтобы открыть Ponder |
| V | Переключить вкладку всплывающей подсказки SimplyTooltips |
| Правый Shift | Сравнить предмет под курсором с экипированным |
| Правый Alt | Показать подробные данные предмета Mekanism |

В Sophisticated Storage для сортировки и переноса предметов есть кнопки в окне хранилища.

## Книга квестов FTB

| Клавиша | Действие |
| --- | --- |
| 0 | Сбросить масштаб |
| Пробел | Центрировать карту |
| Ctrl + F | Поиск квестов |
| F1 | Показать расширенную информацию о квесте |

Колесо мыши меняет масштаб. Карту можно перетаскивать мышью, главы выбирать на боковой панели, а настройки открыть кнопкой в окне квестов.

## EMI

| Клавиша | Действие |
| --- | --- |
| Ctrl + O | Показать или скрыть панель EMI |
| Ctrl + F | Перейти в строку поиска EMI |
| R / ЛКМ | Показать рецепты получения предмета. Щелчок работает по записи EMI |
| U / ПКМ | Показать применения предмета. Щелчок работает по записи EMI |
| A | Добавить предмет под курсором в избранное или убрать оттуда |
| Ctrl + ЛКМ | Назначить рецепт по умолчанию в списке рецептов |
| Backspace | Вернуться к предыдущей странице EMI |
| ЛКМ | Создать одну порцию через кнопку быстрого крафта |
| Shift + ЛКМ | Создать максимум через кнопку быстрого крафта |
| Левый Shift | Показать кнопки быстрого крафта EMI |

В обычном инвентаре `Shift + ЛКМ` быстро переносит стопку. `1–9` перемещают предмет под курсором в слот хотбара. Mouse Tweaks позволяет переносить предметы колесом и раскладывать их протягиванием мыши.
