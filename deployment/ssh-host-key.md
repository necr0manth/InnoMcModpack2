# Ключ SSH-хоста для деплоя

В GitHub откройте **Settings → Secrets and variables → Actions → Variables** и задайте `SFTP_HOST_KEY`. Значение — одна строка публичного ключа в формате OpenSSH, например `ssh-ed25519 AAAAC3…`. Существующие `SFTP_HOST`, `SFTP_PORT` и пароль используются как прежде.

Берите ключ у провайдера или из панели сервера. Ключ должен принадлежать сервису на адресе и порту из `SFTP_HOST` и `SFTP_PORT`. Встроенный SFTP хостинга может использовать другой ключ, чем SSH для администрирования. Если провайдер сообщает только отпечаток, получите кандидат через `ssh-keyscan -p ПОРТ ХОСТ` и сверьте его через `ssh-keygen -lf ФАЙЛ_С_КЛЮЧОМ`. После совпадения сохраните только тип ключа и его Base64 из строки `ssh-keyscan`.

SFTP, rsync, диагностика и Update World Configs используют эту переменную. При пустой переменной workflow останавливается. При несовпадении ключа подключение прерывается до отправки пароля. При плановой смене ключа сначала подтвердите новый ключ у провайдера, затем обновите переменную.
