# Управление в игре

Клавиши указаны для латинской раскладки. В обычном режиме колесо мыши меняет слот хотбара.
Назначения можно изменить в **Настройки → Управление → Назначение клавиш**.

## Minecraft

| Клавиша | Действие |
| --- | --- |
| W / A / S / D | Движение |
| Пробел | Прыжок, всплытие или подъём в творческом полёте |
| Левый Shift | Красться, спускаться в творческом полёте или спешиться |
| Левый Ctrl | Бег |
| ЛКМ | Атаковать или ломать блок |
| ПКМ | Использовать предмет, поставить блок или взаимодействовать |
| СКМ | Выбрать блок под прицелом |
| E | Открыть инвентарь |
| Q | Выбросить предмет. Ctrl + Q выбрасывает стопку |
| F | Поменять предметы в основной и второй руке |
| 1–9 | Выбрать слот хотбара |
| T | Открыть чат |
| / | Открыть чат со слешем для команды |
| Tab | Показать игроков на сервере |
| L | Открыть достижения Minecraft |
| P | Открыть список социальных взаимодействий |
| F2 | Сделать скриншот |
| F5 | Сменить вид камеры |
| F11 | Переключить полноэкранный режим |

## Физика, перекат и эмоции

| Клавиша | Действие |
| --- | --- |
| R | Перекат в направлении движения |
| G | Схватить сборку или отпустить её без удержания кнопок мыши |
| X | Удерживать для поворота захваченной сборки мышью |
| Левый Alt | Сменить точку поворота при вращении или отсоединить блок от физической сборки вместе с приседанием и захватом |
| Q | Вернуть захваченную сборку в мир обычными блоками, если она выровнена |
| Левый Alt + Q | Объединить выровненные физические сборки |
| Запятая | Переключить режим, в котором установленные блоки сразу становятся физическими объектами |
| H | Дать пять другому игроку |
| J | Зажать и отпустить рядом с другим игроком для приветствия Dap |

Для захвата Barehanded освободите руку, наведитесь на сборку и удерживайте ЛКМ и ПКМ. Пока сборка захвачена, колесо мыши подтягивает или отодвигает её. Чтобы отделить блок от мира, присядьте, удерживайте обе кнопки и отойдите назад. Удар захваченной сборкой о блок может вернуть её в мир обычными блоками при достаточной скорости и подходящем положении. [Управление Barehanded](https://modrinth.com/mod/barehanded)

Все эмоции Quark, включая взмах рукой, доступны по кнопке «Эмоции» в чате.

## Карта, рюкзак и строительство

| Клавиша | Действие |
| --- | --- |
| M | Открыть карту мира Xaero |
| B | Открыть экипированный рюкзак |
| Клавиша слева от 1 | Открыть меню ближайших ящиков с инструментами Create |
| Левый Shift | Показать детали в подсказке Jade под прицелом |
| Левый Shift / Ctrl / Alt | Модификаторы взаимодействий Create |

Экипировку Accessories и книгу квестов FTB можно открыть кнопками в инвентаре.

## Транспорт и специальные режимы

| Клавиша | Действие |
| --- | --- |
| Delete | Прервать кат-сцену |
| \ | Покинуть транспорт RFTools |
| Num 1 | Переключить управление с кресла Synaxis |
| Num 0 | Открыть назначения клавиш кресла Synaxis |
| End | Выйти из режима камеры Gadgets & Gizmos |
| Home | Выйти из режима чтения планшета Create Thrusters |
| Insert | Выйти из режима ввода контроллера Create Thrusters |
| Правый Ctrl | Вырваться из захвата клешни Create Thrusters |

`Esc` открывает меню паузы, `F1` скрывает интерфейс, `F3` открывает отладочный экран.
Эти клавиши встроены в Minecraft.
